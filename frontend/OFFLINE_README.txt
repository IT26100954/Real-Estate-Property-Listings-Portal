Windows x64 offline dependencies for the supplied Haven React frontend. Tested using Node 24.21.0 and Vite 8.3.4. Extract this ZIP into the existing frontend folder so frontend/node_modules/vite/bin/vite.js exists. Stop pending npm installs first. No npm install is needed. From frontend run: node node_modules\vite\bin\vite.js
Keep Java backend running on 8081. Open http://localhost:5173/. Do not commit node_modules or this dependency ZIP to Git. This bundle contains installed third-party packages and their licenses; package.json and the source remain in the complete project ZIP. Windows x64 only; teammates on other platforms should install from the lockfile.
